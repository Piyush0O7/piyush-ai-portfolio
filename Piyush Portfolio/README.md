# Piyush Bindua — AI Engineer Portfolio

A cinematic, interactive single-page portfolio based on Piyush Bindua's current AI Engineer resume.

## Features
- Responsive editorial/AI aesthetic
- Three.js neural-field background
- GSAP scroll reveals and micro-interactions
- Custom cursor + magnetic buttons
- Project case-study modals
- Command palette (Ctrl/Cmd + K)
- Light/dark theme
- Mobile-friendly layout
- GitHub / LinkedIn / email / phone links

## Run locally
Open `index.html` directly, or use:

```bash
python -m http.server 8000
```

Then open http://localhost:8000

## Deploy
This is a static site. Drop the folder into Vercel, Netlify, GitHub Pages, or Cloudflare Pages. No build step is required.

## Resume source
Content was adapted from the supplied Piyush AI resume. Keep project metrics and role dates aligned with the latest resume version.
